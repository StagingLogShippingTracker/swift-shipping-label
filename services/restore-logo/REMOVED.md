# Retired

This folder is a stub only. There is no deployable logo-restore service.
A Fly.io RealESRGAN app used to live here; do not recreate or `fly deploy` it.

Logo restore is Gemini in the Windows/Android apps (`LogoRestorer` + `GeminiClient`).
If Gemini is unavailable, the app uses a local predicted-edge rebuild.
Offline Windows can also run repo-root `logo_restorer.py` locally.
